# KINETIDE Support Site

Static GitHub Pages-ready support portal for KINETIDE Desktop Pro.

## Publish Options

1. Create a public GitHub repository, for example `kinetide-support`.
2. Upload these files to the repository root.
3. Enable GitHub Pages from `main` branch `/root`.
4. Point the Desktop App support URLs to the published site.

## Replace Before Publishing

- Pricing and billing instructions, if you want those public.
- GitHub Pages repository/account decision.
